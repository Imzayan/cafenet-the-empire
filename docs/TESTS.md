## تخفیفِ تأمین‌کننده (باگِ شماره‌دار)

- پولِ ناکافی → تخفیف **مصرف نشد** ✓ / پولِ کافی → خرید با قیمتِ تخفیفی و مصرفِ تخفیف ✓
- rebuy با تخفیف: پایه ۸٫۰M → پرداختِ ۶٫۴M (دقیقاً ۲۰٪) ✓

## گوشه‌ی کنسول (سیستمِ جدید)

- روتِ گیمر → راه‌رفتن → نشستن → پرداخت ۴۵٬۰۰۰ و آزادشدنِ ایستگاه ✓
- تأییدِ بصری: تلویزیونِ روشنِ آبی، مبل، دسته‌ی صورتی، فرش (اسکرین‌شات + اسکنِ پیکسلی) ✓
- ثبت‌نامِ تورنمنت از کنسول ✓

## ذخیره‌سازی و مقاوم‌سازی

- خرابیِ ذخیره‌ی اصلی → بازیابیِ خودکار از پشتیبان ✓ (هفته‌ی ۹ نجات یافت)
- خرابیِ هر دو → شروعِ امن با پیش‌فرض، بدونِ کرش ✓
- مهاجرتِ v2 → rivals ساخته شد (r2 آلایو، شهرت ۶۰)، بانک/صدا/stats برگشت ✓
- مهاجرتِ v1 (بدونِ نسخه) → money/week/up/rivalFame برگشت، ver→3 ✓
- ذخیره‌ی ناقصِ ({money}) → بقیه پیش‌فرض + rivalsِ lazy ✓

## نمایش‌ها و کارایی

- موبایلِ عمودی 375×667: ۶ عنصرِ HUD داخلِ دید، بدونِ سرریزِ افقی، **۶۰fps** ✓
- لن‌اسکیپ 740×360: بدونِ سرریزِ عمودی، مودال کامل جا می‌شود ✓
- دسکتاپ 1280×800: چیدمانِ وسط‌چینِ تمیز ✓
- فونت: `document.fonts.check('12px Vazirmatn')` و bold هر دو true ✓
- ورودی: Pointer Events (موس + لمس یک‌جا) + `touch-action: manipulation` ✓
- خطای کنسول: **۰** در جلسه‌ی کامل با مرورگرِ تازه ✓
