# راهنمای نصب — CAFENET: THE EMPIRE v1.7.0 (versionCode 8)

## نصب روی دستگاه (مالک / بازیکن)
1. فایلِ `cafenet-empire-v1.7.0.apk` را دانلود کن (یا نسخهٔ zip اگر مرورگرِ فایلِ apk را بلاک کرد).
2. روی اندرویدِ ۵ به بالا باز کن؛ اگر پیامِ «منابع ناشناس» آمد، اجازهٔ نصب برای مرورگرِ دانلود را بده.
3. روی نسخه‌های قبلیِ همین بازی (تا v1.6.1 / vc7) **مستقیم نصب می‌شود** — حذفِ نسخهٔ قبل لازم نیست، ذخیره‌ها حفظ می‌شوند.
4. در App info باید «کافه‌نت: امپراتوری — 1.7.0» دیده شود.

## پیش‌نیازهای امکاناتِ مونتیزیشن
- **خریدِ درون‌برنامه‌ای**: نصبِ مایکت روی دستگاه + ورود به حسابِ مایکت + تنظیمِ `IAB_PUBLIC_KEY` در بیلد (بخشِ راهنمای مایکت). تا پیش از آن، دکمه‌ها پیامِ صادقانه می‌دهند و هیچ خریدِ جعلی انجام نمی‌شود.
- **تبلیغِ جایزه‌دار**: اتصالِ اینترنت + تنظیمِ `TAPSELL_REWARDED_ZONE` واقعی از کنسولِ ناشر (پیش‌فرضِ فعلی = محیطِ آزمایشیِ رسمیِ نمونهٔ تپسل، برچسب‌خورده).
- **Backend**: تنظیمِ `SERVER_URL` (https). بدونِ آن، بازی کاملِ آفلاین است؛ فقط خرید/تبلیغ/بتل‌پسِ ابری خاموش‌اند.

## حفظِ پیشرفت
- ذخیره‌سازیِ محلی (`localStorage`) دست‌نخورده؛ نسخهٔ ساختار (v3) با مهاجرتِ افزودنیِ فیلدهای تازه (الماس/ووچر/آخرین درآمد).
- هیچ‌گاه saveها پاک نمی‌شوند؛ پشتیبانِ خودکارِ داخلی (کلیدِ bak) در خرابی بازیابی می‌کند.
