# CAFENET: THE EMPIRE — Art Direction v1 (فازِ ۲)

هویتِ بصری: **«نئونِ تاریکِ شبانه‌ی کافه‌ی گیمینگ»** — پایه‌ی سرمه‌ایِ عمیق، لهجه‌های نئونی، خواناییِ بالا در سایزِ کوچک.

## ۲. قواعدِ سبک (برای هر assetِ جدید — الزامی)

1. **سه‌پله‌ایِ سایه:** هر حجم = رنگِ پایه + لایه‌ی تیره‌ی پایین (alpha≈.3) + rim-lightِ روشنِ ۱px روی لبه‌ی بالا/راست. بدونِ بافتِ فوتوریالستیک.
2. **خطِ دورِ تیره‌ی ۱px** (`rgba(0,0,0,.28…4)`) برای جداسازی از زمینه؛ خطِ دورِ روشن (`rgba(255,255,255,.1…16)`) برای لبه‌ی نوری.
3. **هر چیزِ درخشان = putGlow** با آلفای سقف‌دار (محرمانه: ≤.55 برای صفحه، ≤.15 برای محیط).
4. **نئون = hsla با چرخشِ hue** بر اساس `G.t` (سرعتِ ~36–40 درجه/ثانیه، فازِ متفاوت به‌ازای هر شناسه).
5. **حجمِ انسانی:** اعضای جدا — پا (فازِ راه‌رفتن)، تنه، دست (پوزِ مستقل)، سر + موی استایل‌دار؛ هرگز یک تصویرِ ثابت کشیده نشود.
6. **RTL-پسند:** همه‌ی متن‌ها با `faText` (فونتِ وزیرمتنِ embedشده)، اعدادِ فارسی با `faNum`.
7. **صرفه‌ی کارایی:** هر چیزِ ثابت → `bgCanvas` (یک‌بارِ ساخته‌شده)؛ فقط پویاها per-frame؛ ذرات با سقف؛ گرادیان‌های تکرارشونده کش شوند.

## ۳. مشخصاتِ شخصیت‌ها

- آرکتایپِ ۱۱گانه، هر یک: رنگِ لباسِ اختصاصی، نسبتِ بدن (`hMul` 0.85–1.06: نوجوان کوتاه‌تر، دارا/حرفه‌ای بلندتر؛ `wMul` 0.92–1.14)، تُنِ پوست، استایلِ مو (buzz/spiky/bun/long/curly/cap)، اکسسوری (عینک برای work/student؛ هدف‌فن برای gamer/esports هنگامِ نشستن).
- جدولِ انیمیشن (متادیتا در `ANIMS`): `walk / idle / sit / typing / drink / celebrate / angry / disappoint / talk` — هر پوز = رفتارِ مستقلِ دست‌ها + سر + تنفسِ تنه؛ گذارها با فِیدِ کوتاه و بدونِ پرش.

## ۴. مشخصاتِ محیط

- **میز:** رویه + پایه‌ی دوتایی + پنلِ کناری، RGB زیرمیز (hue-chase)، مانیتور با قاب/پایه/LED/بوتِ نرم، کیبوردِ کلید‌دار، ماوس، کیس با فنِ RGB چرخان، لیوانِ چای هنگامِ سرو، هدف‌فنِ روی میزِ گیمرها.
- **فروشگاه‌های خودکار:** دستگاهِ نوشیدنی (رِوِ لامپ‌دار) و قفسه‌ی اسنک، در ناحیه‌ی پایینِ راست (خارج از مسیرِ میزها و نظافتچی).
- **دیوار/کف:** کاشیِ پرسپکتیو با بندِ تیره، وینیتِ ملایم، واِین‌سکات و تریم (وابسته به ارتقای wall)، قابِ پوسترهای گیمینگ روی دیوارِ بالا.
- **نور:** دو لامپِ سقفی با cone (فلِکرِ ظریف)، هاله‌ی مانیتورِ additive، تینتِ محیطیِ زمانِ روز (صبحِ خنثی → روزِ روشن → عصرِ گرم → شبِ آبیِ عمیق)، پنجره‌ی شبانه با ماه.
- **VIP:** طلاییِ مات، رِوِ قرمزِ پرده، فرشِ الیتی — بدونِ زرق‌وبرقِ اضافه.

## ۵. سقف‌های فنی (نگهبانِ ۶۰fps)

- glow محیطی ≤ ۱۲ نقطه در فریم؛ ذرات ≤ ۶۰؛ bubble هم‌زمان ≤ ۴؛ هیچ گرادیانِ جدیدِ هر‌فریمیِ بی‌کش؛ همه‌ی staticها در bgCanvas.
