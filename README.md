# CAFENET: THE EMPIRE

شبیه‌سازِ تجاریِ مدیریتِ کافه‌ی اینترنتی — فارسی، راست‌به‌چپ، کاملاً آفلاین، تک‌فایلِ قابلِ اجرا.

> مسیرِ محصول: از کافه‌ی کوچکِ به‌ارث‌رسیده تا امپراتوریِ گیمینگِ شهر — با روایتِ فصل‌بندی‌شده، اقتصادِ واقعی، رقبای زنده و ای‌اسپورتس.

## اجرا

**دسکتاپ (ویندوز/مک/لینوکس):** فایلِ `cafnet.html` را باز کنید (کروم/فایرفاکس/اج). هیچ نصب، سرور یا اینترنتی لازم نیست؛ فونت و همه‌ی منابع داخلِ خودِ فایل‌اند. از منویِ مرورگر هم می‌توان «نصب به‌عنوان اپ» را انتخاب کرد.

**اندروید (امروز):** `cafnet.html` را به گوشی منتقل و با کروم باز کنید — ذخیره‌ی خودکارِ محلی، ۶۰fps اندازه‌گیری‌شده، لمسِ کشیدن/زوم.
(نسخه‌ی APK/AAB با Capacitor در فازِ ۶ ساخته می‌شود — تا آن زمان ادعایی از وجودِ آن‌ها نمی‌شود.)

## کنترل‌ها

- کلیک/لمس: تعامل با میزها، دکمه‌ها، منوها
- درگِ افقی: جابه‌جاییِ دوربین · چرخِ موس یا ＋/−: زوم
- ESC: بستنِ فروشگاه/داشبورد، خروج از توقف · ⏸ گوشه: توقفِ دستی

## ساختارِ مخزن

```
cafnet.html        ← بازیِ کاملِ buildشده (این فایل را اجرا کنید)
src/               ← سورسِ پنج‌بخشی + build.sh + فونتِ وزیرمتن (base64، مجوزِ SIL OFL)
patches/           ← تاریخچه‌ی کاملِ پچ‌ها (هر تغییر یک اسکریپتِ قابلِ بازبینی)
docs/
  AUDIT.md         ← ممیزیِ فنیِ فازِ ۱ (۸ بخشِ الزامیِ پرامپت)
  ROADMAP.md       ← نقشه‌ی راهِ فازها و وضعیتِ هر کدام
  CHANGELOG.md     ← تغییراتِ نسخه‌ها
  TESTS.md         ← تست‌های واقعاً اجراشده
  BUGFIXES.md      ← فهرستِ باگ‌های رفع‌شده
```

## ساختِ دوباره از سورس

```bash
cd src && bash build.sh   # خروجی: cafnet.html
```

سورس در ۵ فایلِ ماژولار است: `p1_head.html` (استایل/DOM)، `p2_core.js` (داده/ذخیره/صدا)، `p3_sim.js` (شبیه‌سازی)، `p4_scene.js` (رندر)، `p5_ui.js` (رابط).

## ذخیره‌سازی

- نسخه‌ی v3 با مهاجرتِ خودکارِ v1/v2، پشتیبانِ هر ۸ ذخیره و بازیابیِ خودکار از خرابی.
- ذخیره‌ی خودکار در خرید/پایانِ روز/beforeunload + دکمه‌ی ذخیره‌ی دستی (💾) در منوی مکث.
- پاک‌کردنِ دستی: کنسولِ مرورگر → `localStorage.clear()`

## قواعدِ توسعه (خلاصه؛ جزئیات در docs/AUDIT.md §8)

1. هسته‌ی Canvas حفظ می‌شود — مهاجرتِ موتور فقط با داده‌ی پروفایل و دلیلِ مستند.
2. هر زیرسیستمِ جدید: سورسِ مجزا + feature-flag + مسیرِ defaults→merge→migration در ذخیره.
3. هیچ دکمه‌ی بی‌عملکرد، هیچ ادعای بی‌تست، هیچ پرداختِ شبیه‌سازی‌شده‌ی «واقعی».
