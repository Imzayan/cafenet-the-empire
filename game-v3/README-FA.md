# CAFENET: THE EMPIRE — v3.0.0

بازی مدیریت کافه‌نت — HTML5 Canvas خالص، بدون کتابخانه، بدون CDN، **کاملاً آفلاین**. فارسی/RTL، لمسی، پرتره و لنداسکیپ.

## اجرا

فایل `index.html` را در مرورگر باز کن — همین. (برای اندروید: راهنمای `ANDROID_STUDIO.md` یا APK آمادهٔ `cafenet-empire-v3.0.0.apk`)

## ساختار

```
index.html      — بوم، لودر، نوار بالا، دکمه‌ها، پنل‌ها
game.js         — موتور بازی (۱۱ بخش: پیکربندی → داده → ذخیره → لودر → صدا → A* → موجودیت‌ها → رندر → ورودی → UI → حلقه)
assets.js       — فهرست assetها + anchor + جدول SPRITE_SCALE (تولیدشده از ابعاد واقعی)
css/style.css   — تم، RTL، safe-area، پنل‌ها
assets/         — characters / furniture / signs / ui (فقط PNGهای شفافِ بدون _raw)
```

## گیم‌پلی

- مشتری‌ها (kid1..8) از در می‌آیند → چک‌این در پذیرش → مسیریابی A* تا ایستگاه خالی → می‌نشینند → ساعتی تعرفه می‌پردازند → می‌روند.
- تپ روی ایستگاه: تعرفهٔ ساعتی (اقتصاد/استاندارد/لوکس)، ارتقای صندلی (عادی→آبی→بنفش→قرمز)، ارتقای سیستم، تعمیر.
- تپ روی مشتریِ عصبانی: سرویس نوشیدنی/خوراکی/تنظیم سیستم.
- یخچال، آبسردکن، اسنک و دستگاه قهوه = آیتم‌های فروش با موجودی و انعام.
- ۴ کارمند قابل استخدام: سرایدار (نظافت)، گارسون (سرویس خودکار)، باریستا (فروش قهوه)، تکنسین (تعمیر).
- ۱۲ ایستگاه (۶ فعال از اول)، اعتبار که سرعت ورود مشتری را می‌سازد، خرابی سیستم، زباله.
- الماس: تبلیغ محله، کیسهٔ سکه، تعمیر فوری، لوژ VIP.
- ماموریت‌های چرخشی، ۱۰ افتخار، هدیهٔ روزانه با استریک ۷ روزه.
- ذخیرهٔ خودکار: هر ۸ ثانیه + هنگام خروج (`localStorage: cafenet_empire_v3`).
